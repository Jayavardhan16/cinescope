# 🎬 CineScope – Movie Explorer App

Discover movies. Explore cinema. Find your next favourite.

CineScope is a Flutter-based movie discovery application powered by the TMDB API. It helps users explore trending movies, discover Indian cinema, search for movies and people, view detailed movie information, and manage a personal watchlist.
